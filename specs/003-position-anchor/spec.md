# 立ち絵の基準位置(アンカー)を9通りから選ぶ

> spec.md — フィーチャーの「何を・なぜ」。正本はこのテキストと GitHub(Feature issue)。

## 目的
立ち絵を置く**基準(アンカー)を 左/中央/右 × 上/中央/下 の9通りから選べる**ようにする。
現状の「左端・下端からの px」固定をやめ、右寄せ・中央寄せ・上寄せを解像度非依存で指定できる状態にする。

## 背景 / 課題
- 現状の出力は `position: fixed; left: <X>px; bottom: <Y>px;` の決め打ち
  ([`src/lib/generateCss.ts:132`](../../src/lib/generateCss.ts))。基準は常に**左下**。
- **右端に置くのが実質できない。** 「キャンバス幅 − 立ち絵幅 − 余白」を人間が計算して `left` に入れる必要があり、
  OBS のキャンバス解像度や立ち絵の幅を変えるたびに破綻する。
- **中央寄せも同様。** 幅を「原寸」(= `width` 未指定)で使っている場合は、そもそも人間が計算できない。
- 複数人を左右に振り分ける配置(自分は右下・相手は左下 など)が定番だが、今は数値の当てずっぽうになる。

## スコープ
- **含む**:
  - プリセットに **横アンカー(`left`/`center`/`right`) × 縦アンカー(`top`/`middle`/`bottom`)** を持つ。
  - オフセット(px)の意味を**選んだアンカーからの距離**に変更する(右アンカーなら右端から、など)。
    中央は `50%` + `transform: translate()`。
  - **発話演出(ぴょこぴょこ)との `transform` 衝突の解消**(下記「降りる箇所」)。
  - **プレビューがアンカーに追従**する(貼る前に右寄せ・中央寄せの見え方を確認できる)。
  - **後方互換**: アンカー未設定の既存プリセット(localStorage 保存分)は **左下** として読み、
    出力が従来と一致する。
  - UI: 9通りを選ぶコントロール(3×3 のグリッド等)とオフセットのラベル追従
    (「左端からの距離」→ アンカーに応じた文言)。
- **含まない**:
  - **キャンバス解像度の切替UI**。プレビューは 1920×1080 基準のまま(アンカー指定の効果は解像度非依存なので、
    このフィーチャーの受け入れには不要)。
  - **名前ラベル(002)のアンカー対応**。名前は 002 の「立ち絵からの相対位置」に従うため、
    立ち絵アンカーの変更に自動追従すれば足りる。
  - 回転・スケール・反転などの変形。
  - まとめ版 `generateCombinedCss` のアンカー対応(UI から呼ばない温存コード。型の整合だけ取る)。

## 受け入れ条件
- [ ] 9通りのアンカーを UI で選べ、出力CSSに反映される(`left`/`right`/`top`/`bottom`/`50%` の出し分け)
- [ ] **中央寄せ + ぴょこぴょこ ON で立ち絵が飛ばない**(中央寄せの `transform` がアニメで打ち消されない)
- [ ] 右・上アンカー指定時、OBS キャンバス解像度が変わっても**指定した端からの距離が保たれる**
- [ ] 幅が「原寸」(`width` 未指定)でも中央寄せが成立する
- [ ] **既存の保存済みプリセット**(アンカー無し)が左下として読め、出力が従来と**バイト一致**する
- [ ] プレビューがアンカーに追従する
- [ ] 9通り × 発話演出の組み合わせを vitest で固定する(既存テストは壊さない)

## メモ / 降りる箇所
- **`transform` 衝突が本体の難所。** 中央寄せを `transform: translate(-50%, …)` で実現すると、
  ぴょこぴょこの `@keyframes speak-jump { transform: translateY(…) }`
  ([`src/lib/generateCss.ts:46`](../../src/lib/generateCss.ts)) が中央寄せを**上書きして立ち絵が飛ぶ**。
  対応案は3つ。**実装時に判断する(降りる箇所)**:
  1. **keyframes 側に中央寄せ分を織り込む**(`translate(-50%,-50%) translateY(-8px)` を生成)。
     既に `jumpKind: 'transform' | 'bottom'` の分岐があるのでそこに乗る。**推し。**
  2. 中央寄せのときだけ既存の `KEYFRAMES_JUMP_BOTTOM`(`bottom` を動かす版)に切り替える。
     縦中央アンカーとは相性が悪い。
  3. `calc(50% - 幅/2)` で寄せて `transform` を使わない。**幅が原寸(未指定)だと使えない**ため、
     受け入れ条件「原寸でも中央寄せ」を満たせない。
- **002(名前表示)と同じファイルを触る**(`types.ts` / `generateCss.ts` / `TachiePreview.tsx` / `PresetPanel.tsx`)。
  002 が先行しているので、**002 のマージ後に着手**しないとコンフリクトする。
- `Preset` は localStorage に保存される。アンカー追加は**任意フィールド + 既定値**で入れ、
  既存データの読み込みを壊さないこと。
