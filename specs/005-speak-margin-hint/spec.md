# 発話演出に必要な余白を距離の入力欄に出す

> spec.md — フィーチャーの「何を・なぜ」。正本はこのテキストと GitHub(Feature issue)。
> 出所: rail #795。

## 目的
プリセット編集の「アンカーからの距離」の入力欄の近くに、**発話演出(枠・後光 / ぴょこぴょこ)が端で切れないために必要な距離**を出す。
足りないときは警告、足りているときは小さく必要値を書く。**既定値と出力CSSは変えない。表示を足すだけ。**

## 背景 / 課題
- 枠・後光は `drop-shadow` のぼかしが脈動し、立ち絵の外へ**幅のおよそ 6 倍**広がる(2026-09-11 に OBS 実機 1920×1080 で実測:
  幅2→12px / 幅4→23px / 幅6→34px / 幅12→69px。理論値は 6×幅)。
  2026-09-18 に OBS 32.1.2・1920×1080 で再計測したところ幅 2/4/6/12 → 13/26〜27/34〜40/79〜80px と最大約 6.7× まで広がったため、7×幅に上げた。
- ぴょこぴょこは**上方向にだけ**動く(`translateY(-跳ね高さ)`)。
- 距離の既定は 2026-09-11 に 0 にした(PR #30)。**既定のままだと既定の枠(幅2)でも端で切れる**のに、UI は何も知らせない。

## スコープ
- **含む**:
  - 発話演出の設定とアンカーから、横・縦それぞれの必要余白(px)を返す純粋関数。
  - 距離の入力欄(横・縦)への表示: 距離 < 必要値なら警告、距離 ≥ 必要値なら補足文で必要値。必要値が 0(演出なし)なら何も出さない。
  - 中央アンカーの軸(「中央からのズレ」の欄)には出さない。
- **含まない**:
  - 既定値の変更、出力CSS(`src/lib/generateCss.ts`)の変更。
  - まとめ版 `generateCombinedCss`(Streamkit のレイアウト内で動く・UI から呼ばれない)。
  - 実ブラウザ(Playwright)での画面テスト(spec 004 の PR #42 が未マージのため。表示は文字 1 行)。

## 受け入れ条件
- [ ] 枠・後光 ON・幅 4、右下アンカー、距離 0 のとき、距離の入力欄に「28px 以上」を求める警告が出る(7×4=28。実測 26〜27px より安全側)。
- [ ] 同じ設定で距離を 28 以上にすると警告が消え、補足文に「必要な余白: 28px」が出る。
- [ ] 幅を 2 に戻すと必要値は 14px になり、距離 16 なら警告ではなく補足文になる。
- [ ] 上アンカー + 枠・後光 幅 2 + ぴょこぴょこ 10px のとき、縦の必要値は 24px(14 + 10)。下アンカーでは 14px(跳ね量を足さない)。
- [ ] 中央アンカーの軸の欄には余白の表示が出ない。枠・後光もぴょこぴょこも OFF なら、どの欄にも出ない。
- [ ] `src/lib/generateCss.ts` と `src/lib/generateCss.test.ts` に差分が無い(= 出力CSSは不変)。既定値(`DEFAULT_OPTIONS` / `DEFAULT_SPEAK`)の**値**に差分が無い(doc コメントの書き換えは除く)。
- [ ] plan.md の `test` が緑。
- [ ] OBS 実機で、表示どおりの距離(枠・後光 幅4 → 28px)にすると枠・後光が端で切れない。
