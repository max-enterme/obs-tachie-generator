# 立ち絵に任意の名前を表示する

> spec.md — フィーチャーの「何を・なぜ」。正本はこのテキストと GitHub(Feature issue)。

## 目的
立ち絵の横/下に **任意のテキスト(名前)** を出せるようにする。Discord のアカウント名ではなく、
配信で見せたい呼び名(例: 本名でない配信名義・ロール名・チーム名)をそのまま出せる状態にする。

## 背景 / 課題
- 001 の出力CSSは Streamkit の実要素を全部潰している
  (`img { display: none !important }` / `[class*="Voice_name__"] { display: none !important }`)。
  → **Discord 側の名前は原理的に出ない**。名前を出すなら CSS 側で描くしかない。
- Streamkit の名前をそのまま出す道もあるが、それだと **Discord アカウント名に固定**され、
  「配信で見せたい名前」と一致しない(配信名義と本アカウント名が違うのは普通)。
- 立ち絵だけだと「誰の立ち絵か」が視聴者に伝わらない場面がある(初見・複数人配信)。

## スコープ
- **含む**:
  - **ユーザーごとに「画面に出す名前」を持つ**(`AppUser.displayName`)。空ならメモ用の表示名
    (`AppUser.name`)を流用する。→ 名前は「誰」に属し、見た目のプリセットは複数人で使い回せるまま。
  - **プリセット側に名前の見た目**(`Preset.nameLabel`)を持つ: 表示ON/OFF・立ち絵からの相対位置(x/y)・
    文字サイズ・フォント・色・太字・行揃え・縁取り(色/幅)。
  - **行揃えの基準幅**: 立ち絵に `width` 指定があればそれ、**原寸(未指定)ならアプリ側で測った画像の実サイズ**を
    名前の箱幅として出力CSSに焼き込む(CSS からは描画中の画像の実寸を参照できないため)。
  - **背景(テロップ帯)**: 名前の箱そのものに背景色・不透明度・余白(縦横)・角丸を付ける
    (擬似要素は増やさない)。帯の幅は **文字に合わせる / 立ち絵の幅いっぱい** の2モード。
    「文字に合わせる」は `width` を出さず(＝文字幅に縮む)、立ち絵に対する位置は `transform: translateX()` で合わせる。
  - 出力CSSは **`body::before` の `content`** で名前を描く(立ち絵は `body::after` を使用済み)。
    → **1ペア = 1ブラウザソース = 立ち絵1枚 + 名前1つ**。
  - **「通話にいないときは隠す」に名前も追随**する(立ち絵と一緒に出入りする)。
  - **触れない入力は理由を画面に出す**(行揃え・縁取り・発話演出。無効の見た目も統一する)。
  - プレビューに名前を表示し、貼る前に位置・サイズ・縁取りを確認できる。
- **含まない(このフィーチャー)**:
  - 名前の発話演出(話すと名前も跳ねる/光る)。名前は静止したネームプレートとして扱う。
  - 「静かな人を暗くする」の名前への適用(可読性のため常に等倍で出す)。
  - まとめ版(`generateCombinedCss`)への名前対応。まとめ版は UI から呼ばない温存コードのため。
  - 複数行の名前(改行は空白に潰す)。
  - 帯の枠線・グラデーション・影などの追加装飾(色・不透明度・余白・角丸まで)。

## 受け入れ条件
- [x] ユーザーに「画面に出す名前」を入力でき、登録済みユーザーも後から変更できる
- [x] 「画面に出す名前」が空なら、メモ用の表示名がそのまま名前として使われる
- [x] プリセットで名前表示を ON にすると、出力CSSに `body::before { content: "<名前>" }` が出る
- [x] 名前の位置が **立ち絵の left/bottom からの相対**で指定でき、出力CSSに反映される
- [x] 文字サイズ・色・太字・縁取り(色/幅)・フォント・行揃えが出力CSSに反映される
- [x] 幅が原寸(未指定)でも、画像の実サイズを基準に行揃えが使える(実測値を焼き込み・注記あり)
- [x] 触れない入力は理由が画面に出る(行揃え / 縁取り / 発話演出の各欄)
- [x] 名前に背景(テロップ帯)を敷ける。色・不透明度・余白・角丸が出力CSSに反映される
- [x] 帯の幅が「文字に合わせる」「立ち絵の幅いっぱい」で切り替わり、どちらも立ち絵に対して位置が合う
- [x] 名前表示 OFF、または名前が空のときは `body::before` を出さない(既存出力と同一)
- [x] `hideWhenAway` のとき、名前も在室時だけ表示される
- [x] 名前に `"` `\` 改行 `}` を含めても CSS が壊れない(エスケープ・単一行化)
- [x] 色・フォント名に不正値を入れても CSS 注入にならない(安全側に倒す)
- [x] プレビューに名前が出て、位置・サイズ・縁取りが実出力と一致する
- [x] 既存プリセット(nameLabel を持たない localStorage)を読んでも壊れず、既定は表示OFF
- [ ] OBS 実機に貼って、名前が意図どおり出る(§08 実機確認・T8)

## メモ / 降りる箇所
- **描画枠の上限**: 立ち絵=`body::after` / 名前=`body::before` で、**1ソースあたり擬似要素は使い切る**。
  これ以上の常時表示要素(2人目・背景板など)は同じソースには足せない。増やすなら 003(コンポジタ)側で
  「1配置=1ブラウザソース」を増やす方向で解く(**降りる箇所**: 同一ソースに要素を増やす設計にはしない)。
- **重なり順**: `::after`(立ち絵)は `::before`(名前)より後に描かれるため、名前を立ち絵に重ねる位置に
  置くと隠れる。名前側に `z-index: 1` を置いて前面に出す。
- **行揃えの基準幅は「焼き込み」**: 幅が原寸のときは画像の実サイズを CSS に数値で埋める。
  つまり**画像を差し替えたら CSS を出し直す**必要がある(出力CSSにその注記を入れる)。
  CSS 側で解決する手段は無い(`content: url(...)` の実寸を参照する仕組みが CSS に無い)。
- **フォント**: OBS(CEF)にインストール済みのフォントしか使えない。Web フォントの読み込みは
  Streamkit の CSP で弾かれる前提とし、フォント指定は「環境にある名前を書く」だけにする。
