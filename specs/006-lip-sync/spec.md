# 口パク(話している間だけ口開きの絵と交互に切り替える)

> spec.md — フィーチャーの「何を・なぜ」。正本はこのテキストと GitHub(Feature issue)。
> 出所: 依頼「口パクを入れられるようにしたい」(2026-10-31)。要件はこの一文のみ。

## 目的
プリセットに**口開きの立ち絵を 1 枚**足せるようにし、Discord で話している間だけ、立ち絵(口閉じ)と口開きの絵を**一定間隔で交互に切り替える**。
静かなときは口閉じ(従来の立ち絵)に戻る。

## 背景 / 課題
- 今の発話演出は「ぴょこぴょこ / 枠・後光 / 点滅」で、**立ち絵の中身(口)は動かない**。001 の除外項目に「口パク(`--img-mouth-url`)対応(将来 feature)」とある。
- 1 ブラウザソースは `body::after`=立ち絵 / `body::before`=名前 で擬似要素を使い切っている(002)。**口だけを別要素で重ねることはできない**。
  → 口パクは「口開きの全身絵をもう 1 枚用意し、`body::after` の背景画像を差し替える」形でだけ成立する。
- Streamkit から取れる状態は「話している / 静か」の 2 つだけで、**声の大きさには連動できない**。

## スコープ
- **含む**:
  - プリセットに口開き絵(任意・1 枚)と口パクの回数(「動きの速さ・周期」1 回あたり 1〜4 回)を持たせる。保存・読み込み。未設定のプリセットは従来どおり。
  - 出力CSS: 話している間、立ち絵⇄口開き絵を周期どおり交互に出す(`@keyframes` でステップ切替)。既存の発話演出(ぴょこぴょこ・枠・後光・点滅・暗転)とは併用できる。
  - プリセット編集画面: 口開き絵の設定(アップロード / 画像URL)・外す・口パクの回数の選択・縦横比違いの警告。
  - プレビュー: 「発話」にすると交互に切り替わる。
  - 出力パネルの注意: 立ち絵の実サイズが測れていない間は口パクが出力に入らないことを知らせる。
  - 実ブラウザ(Playwright)での切替の検証。
- **含まない**:
  - 声の大きさに応じた口の開閉(Streamkit から音量は取れない)。
  - 口の形を 3 枚以上(あ・い・う…)。口開き絵は 1 枚だけ。
  - 口だけの画像を立ち絵に重ねる方式(擬似要素が足りない)。
  - 口開き絵のトリミング(立ち絵のトリミングは従来どおり立ち絵だけに掛かる)。
  - 実サイズが測れないとき(従来の `content` 方式)の口パク。
  - まとめ版 `generateCombinedCss`(UI から呼ばれない温存コード)。
  - 名前ラベルへの連動、ユーザーごとの複数画像登録(003 の除外項目 = 別 feature)。

## 受け入れ条件
- [ ] 口開き絵を設定したプリセットの出力CSSに、`:root` の `--img-mouth-url-<id>`、`@keyframes speak-mouth`(0%=立ち絵 / 50%=口開き / 100%=立ち絵)、発話中ルールの `animation` に `<周期>ms infinite steps(1, end) speak-mouth` が入る。
- [ ] 口開き絵を設定していない(未指定・空文字・空白のみ)プリセットの出力CSSは、この feature の前と**1 文字も変わらない**。
- [ ] 口パクの周期は「動きの速さ・周期」÷ 口パクの回数(1〜4 回、既定 2 回)で自動で決まり、ぴょこぴょこ・枠・後光・点滅とずれない(既定 750ms ÷ 2 = 375ms)。動きの速さや回数を変えると出力CSSとプレビューが追従する。回数が 1〜4 の整数でなければ 2 回。計算結果が 50ms 未満なら 50ms に丸める(そのときだけ揃わない)。
- [ ] 実ブラウザ(Chromium)で、発話中の状態にすると周期の前半は立ち絵(口閉じ)・後半は口開き絵が実際に描かれる。静止時は立ち絵だけが描かれる。ぴょこぴょこ・枠・後光を ON にしていても同じ。
- [ ] 口開き絵を設定していても立ち絵の実サイズが測れていないときは、出力CSSに口パクは入らず、出力パネルに「口パクは出力CSSに入りません」と注意が出る。
- [ ] プリセット編集画面で口開き絵をアップロード / 画像URLで設定でき、「口開き絵を外す」で未設定に戻せる。立ち絵が未設定の間は口開き絵の欄は使えない。
- [ ] 口開き絵の縦横比が立ち絵と 1% を超えて違うと、画面に警告が出る(口開き絵は立ち絵の枠に収めて中央に出す)。ほぼ同じ縦横比(差 1% 以内)なら出さない。
- [ ] プレビューで「発話」にすると立ち絵と口開き絵が周期の半分ごとに入れ替わり、「静か」にすると立ち絵に戻る。
- [ ] 口パク追加前に保存されたデータを読み込んでも壊れず、口パクなしとして扱われる。
- [ ] plan.md の `test` が緑。
- [ ] OBS 実機のブラウザソースで、話している間だけ口が交互に切り替わる(人手 T5)。

## メモ / 降りる箇所
- 画面の文言と置き場所はモック(ダッシュボード Pages の `obs-tachie-generator/006-lip-sync-mock.html`)で確定済み(2026-10-31)。確定値は plan.md の「確定値」の表。
- **OBS(CEF)で `@keyframes` の `background-image` 切替が効くかは実機確認が要る**(Chromium では自動テストで確認するが、OBS 内蔵ブラウザは別物)。効かなかった場合の代替(JS を使わない範囲で `animation` の組み立てを変える)は人が決める。実装側で代替に切り替えない。
- 口開き絵を足すと data URI が 2 倍になり、ブラウザの保存容量(localStorage)を超えると**黙って保存されない**(既存の挙動。`src/lib/state.ts` の `saveState`)。この feature では挙動を変えない。埋め込み最大幅(既存欄)で縮めて使う前提。
- **2026-10-31 実装後に変更(本人の依頼)**: 口パクの周期を「手で ms を入れる(既定 300ms)」から「動きの速さ・周期に合わせて自動で決める」に変えた。動きと口パクが同時に始まり、周期が割り切れるのでずれない。詳細は plan.md「## 変更 C1」。
