OBS に、Discord の通話相手を
立ち絵で出す

Discord で通話している人を、アイコンではなく好きな立ち絵で配信画面に出すためのツールです。 話すと立ち絵が動き、口開きの絵を用意すれば口パクもします。 ブラウザだけで使えて、インストールもアカウント登録も要りません。

しくみ

OBS には Discord 公式の「Streamkit」で通話の様子を表示できます。そこに貼る「見た目の指定（CSS）」を、このツールが作ります。

「誰」と「見た目」が分かれているので、たとえば自分の ID で動きを試してから、相手の ID に差し替えるだけで本番用ができます。

できること

設定はどれも、画面下のプレビューですぐ確かめられます。

表示

通話にいなくても出しっぱなし

相手が通話に入る前から、決めた位置に立ち絵が出ます。出入りで位置がずれません。入っている間だけ出す設定もあります。

話すと反応

話すと動く

ぴょこぴょこ跳ねる／枠・後光が光る／点滅、から選べます（組み合わせも可）。話していない人を暗くして、話している人を目立たせることもできます。

話すと反応

口パク

「口を開けた絵」をもう 1 枚用意すると、話している間だけ交互に切り替わります。声の大きさには連動しません。

表示

好きな名前を添える

Discord のアカウント名ではなく、配信で見せたい呼び名を出せます。文字の大きさ・色・縁取り・テロップ帯も選べます。

画像

切り抜きもツールの中で

画像のまわりの透明な余白をボタン 1 つで詰めたり、ドラッグで範囲を決めて切り抜いたりできます。

画像

画像のリンク切れが起きない

画像は CSS の中に埋め込むので、画像を置いておくサーバーが要りません。Discord に貼った画像のリンク（約 24 時間で切れる）も、自動で埋め込みに変えます。

用意するもの

はじめる前にそろえておくと迷いません。

  • OBS Studio（新しめのもの） 古い OBS だと、立ち絵の常時表示や話したときの動きが効きません。OBS 33 で動作を確認しています。
  • Discord アカウント Streamkit の URL を作るときにログインします。通話相手の「ユーザー ID」も Discord で調べます（手順 ① で説明）。
  • 立ち絵の画像 背景が透明な PNG がおすすめです。1 枚 8MB まで。
  • 口を開けた絵（口パクしたいときだけ） 立ち絵と同じ大きさ・同じ構図で、口だけ開けたもの。立ち絵だけ切り抜くと、口開きの絵とずれるので注意。

使い方

ツールの画面上部にある ①〜④ のタブを順に進めます。最後に OBS に貼ります。

  1. ユーザーを登録する

    立ち絵を出したい人の Discord ユーザーID を入れて 追加。

    ユーザー ID の調べ方:

    1. Discord の ユーザー設定 → 詳細設定 → 開発者モード をオン
    2. 相手のアイコンを右クリック → ユーザーIDをコピー

    画面に出す名前 に入れた文字が、配信画面に名前として出ます。 表示名 はツールの中で見分けるためのメモです。

  2. 立ち絵・演出（プリセット）を作る

    「見た目」のセットを作ります。上から順に:

    • 立ち絵画像 — ファイルをアップロードするか、画像の URL を貼る
    • クロップ（切り抜き） — 透明な余白があるなら 余白を詰める（余白があると位置がずれて見えます）
    • 口パク（任意） — 口を開けた絵を入れると口パクします
    • 位置とサイズ — 画面のどの角を基準にするかと、そこからの距離・幅
    • 発話演出 — 話したときの動き
    • 名前表示 — 名前を出すか、出す場所・文字の見た目

    下の プレビュー をクリックすると「話している／静か」を切り替えて確かめられます。プリセットはいくつでも作れます。

  3. 組み合わせて CSS を出す

    ユーザー（ID） と プリセット（見た目） を選ぶと、その 1 組の CSS が下に出ます。 コピー で写し取ります（ダウンロード でファイルにもできます）。

    よく使う組み合わせは 保存 しておくと、あとでクリック 1 つで呼び戻せます。

  4. 席を作る（入れ替わり・任意）

    ゲスト枠のように日によって人が変わる場所は、④ の 新しい席 で席を作り、候補に追加 で人とプリセットを並べます。通話にいる人の立ち絵がその席に出ます。

    何人か同時にいるときはリストの上の人を出し、誰もいないときは何も出ません。順番は 上へ・下へ で変えます。

    位置は 席の位置 で席ごとに 1 つ決めます（誰が出ても同じ位置）。幅・名前・演出は、その人のプリセットのままです。

  5. OBS に貼る

    1. Discord Streamkit Overlay を開き、Install for OBS から Discord でログイン
    2. Voice Widget を選び、サーバーとボイスチャンネルを選ぶ → 出てきた URL をコピー
    3. OBS で ソースの ＋ → ブラウザ を追加し、URL にさっきの URL を貼る
    4. 幅・高さは OBS の画面（キャンバス）と同じ大きさにする（例: 1920 × 1080）
    5. カスタム CSS 欄の中身を消してから、③（席は ④）でコピーした CSS を貼る → OK

    1 人につきブラウザソース 1 つです。3 人出したいなら、③ で 1 人ずつ CSS を出して、ブラウザソースを 3 つ作ります（URL はどれも同じで大丈夫）。入れ替わりの席は、席 1 つにつきブラウザソース 1 つです。

うまくいかないとき

よくあるつまずきと、その直し方です。

立ち絵がまったく出ない
  • カスタム CSS 欄に、最初から入っていた文字が残っていないか確かめる（全部消してから貼る）
  • ① の Discord ユーザー ID が合っているか（名前ではなく数字の ID）
  • OBS が古いと効きません。OBS を最新にする
  • Streamkit の URL が、その人がいるサーバー・チャンネルのものか
立ち絵の位置が思ったところとずれる
  • 画像のまわりに透明な余白があると、その分ずれて見えます。② の 余白を詰める を押す
  • ブラウザソースの幅・高さが OBS のキャンバスと違うと、位置の基準が変わります。同じ大きさにそろえる
話しても動かない
  • ② の 発話演出 がどれもオフだと動きません（ぴょこぴょこ・枠・後光・点滅のどれかをオンに）
  • Discord 側で、その人のマイクが反応しているか（Discord の通話画面で緑の枠が光るか）
  • OBS が古いと効きません
口パクしない・口の位置がずれる
  • 口を開けた絵は、立ち絵と同じ縦横の大きさ・同じ構図にする。違うとツールに警告が出ます
  • 立ち絵を切り抜いたあとは、口を開けた絵も同じように切り抜いたものを入れ直す
  • ③ に「口パクは出力 CSS に入りません」と出ていたら、立ち絵の画像を読み込めていません。画像を入れ直す
  • 口パクは声の大きさではなく、一定の間隔で開け閉めします。速さは ② の 動きの速さ・周期 と 口パクの回数 で変えられます
画像を差し替えたのに OBS の見た目が変わらない

OBS に貼った CSS は、貼った時点のものです。画像や設定を変えたら、③ で CSS をコピーし直して、OBS のカスタム CSS を貼り替えてください。

作った設定はどこに保存される？

いま使っているブラウザの中にだけ保存されます。画像や ID がどこかのサーバーに送られることはありません。 そのかわり、別のパソコンや別のブラウザでは引き継がれません。ブラウザの閲覧データを消すと、設定も消えます。

画像の URL を貼ったら注意が出た

Discord に貼った画像のリンクは、約 24 時間で見られなくなります。URL の扱い が「自動」なら、ツールが画像を CSS に埋め込むので、リンクが切れても立ち絵は消えません。 そのままで大丈夫です。
