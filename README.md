# obs-tachie-generator

OBS で Discord の通話相手を「立ち絵」で表示するための **Discord Streamkit 用カスタムCSS** を、
ブラウザ上で生成する静的Webツール。

**▶ https://obs-tachie-generator.max-enterme.workers.dev/** （インストール不要・ブラウザだけで使えます）

## 特徴（既存ツールとの差分）

- **画像を data URI で埋め込み** — 外部ホスト不要・Streamkit の CSP 回避・URL 失効なし。
- **画像URLの賢い扱い** — Streamkit の CSP が許可する安定ホスト（imgur 等）は **URL のまま**、
  それ以外は **data URI 化**を自動選択。「URL のまま／data URI に変換」の**手動上書き**も可能。
  - ⚠️ **Discord に貼った画像リンク（`cdn.discordapp.com/attachments/...` 等）は約24時間で失効します**（署名付きURL）。
    そのため「自動」では Discord 添付URLだけは **data URI に変換**して埋め込みます（＝失効しない）。恒久運用の要。
- **通話に居ない時も常時表示** — `body::after` + CSS `:has()` で発話も検知して演出。
- **任意の名前を表示** — 立ち絵に添えて **好きな文字列**を出せる（`body::before`）。Discord のアカウント名
  ではないので、配信で見せたい呼び名をそのまま出せる。位置・サイズ・フォント・色・太字・縁取りを指定可。
  - 行揃え（中央/左/右）の基準幅は、幅指定があればその値、**原寸なら画像の実サイズを測って CSS に焼き込み**ます。
    そのため**画像を差し替えたら CSS を出し直してください**（出力にも注記が入ります）。
  - **背景（テロップ帯）**も付けられます（色・不透明度・余白・角丸）。帯の幅は「文字に合わせる」／
    「立ち絵の幅いっぱい」を選べます。
- **プレビュー画面** — 透過（市松）背景の OBS ビューポート風プレビューで、位置・サイズ・発話演出を貼る前に確認。
  画面クリックで 発話⇄静か、通話にいる/いない も切り替えて確認できる（原寸指定時は画像の実サイズで表示）。
- **ユーザーと見た目を分離** — 「誰（Discord ID＋名前）」と「立ち絵・演出プリセット（画像＋位置/サイズ＋演出）」を
  別々に用意し、**出力時にペアで組み合わせる**。自分のIDで反応をテスト → **後からIDだけ差し替え**、が簡単。
- ペアごとの個別出力（1ペア = 1 ブラウザソース・常時表示）、コピー & ダウンロード。

## 使い方（生成ツール・3ステップ）

1. **① ユーザー**：立ち絵を出したい人の **Discord ユーザーID＋表示名** を登録（開発者モード → ユーザー右クリック → 「IDをコピー」）。**「画面に出す名前」**（OBS に出る任意の文字列。空ならメモ用の表示名）もここで指定します（登録後も一覧で変更可）。画像はここでは持たせません。
2. **② 立ち絵・演出プリセット**：再利用する見た目を作る。上段左＝プリセット一覧、上段右＝**画像**（「アップロード」⇄「画像URL」を切替＝排他）＋位置(left/bottom)・幅(width)＋発話演出（ぴょこぴょこ/枠・後光〈色・幅 指定可〉/点滅）＋**名前表示**（ON/OFF・立ち絵からの相対位置・文字サイズ・フォント・色・太字・行揃え・縁取り・背景〈テロップ帯〉）＋静かな人を暗くする＋通話にいないときは立ち絵を隠す、下段＝全幅プレビュー。「オプションを既定に戻す」ボタンあり。複数作れます。
3. **③ 組み合わせ & 出力**：**ユーザー × プリセット**を選ぶ（ユーザー select ＝ テスト用ID↔本番ID の差し替え導線）。**選んでいる1組の CSS がそのまま出力**され、コピー / ダウンロードできます。よく使う組は「保存」で一覧に貯めて、クリックで呼び戻せます。

## OBS / Streamkit への貼り方

1. Discord の [Streamkit Overlay](https://streamkit.discord.com/overlay) で **Voice Widget** の URL を作る。
2. OBS に **ブラウザソース**を追加し、その URL を設定。
3. ブラウザソースの **カスタムCSS** 欄に、生成した CSS を貼り付ける（既存を消してから）。

### 出力は「個別」= 1 ペア = 1 ブラウザソース

- 各ペアの CSS は `body::after` 1要素だけで立ち絵を描画するので、通話に居ても居なくても同じ位置に出て、
  位置ズレが原理的に起きません（**常時表示**）。ペアぶんブラウザソースを分けて貼ります。
- 名前は `body::before` で描きます。擬似要素はこの2つで使い切るため、
  **1ブラウザソースに出せるのは「立ち絵1枚＋名前1つ」**です。
- まとめ版（1ソースに複数人）は提供しません。Streamkit の実アイコン差し替え方式では
  **通話中のユーザーしか出ず常時表示にできない**ため、常時表示できる個別に一本化しています。
  （コアの `generateCombinedCss` は将来用に残置。）

## 仕組み（出力CSSの前提）

Streamkit の実DOMに合わせています:

- アバターは `<img>` 自身。発話中はその img に `Voice_avatarSpeaking__`（ハッシュ付き）クラスが付く。
  → セレクタは `[class*="Voice_..."]` の**前方一致**を使い、Streamkit のクラス名更新に耐えるようにしています。
- 画像URLは `avatars/<ユーザーID>` を含むので、`img[src*="avatars/<id>"]` で人を特定します。
- 立ち絵は `:root` のカスタムプロパティに **data URI** で埋め込みます。

## ⚠️ `:has()` / OBS の注意

常時表示（`body::after`）と発話検知は CSS の **`:has()`** に依存します。

- `:has()` に対応した比較的新しい OBS（内蔵ブラウザ CEF が `:has()` 対応）が必要です。
- 古い OBS では **常時表示・発話演出が効きません**。その場合は OBS を更新してください
  （本ツールは意図的に JS フォールバックを持たず、実証済みの `:has()` 実装に一本化しています）。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型チェック（tsc --noEmit）
npm run lint       # ESLint
npm test           # vitest（1回実行）
npm run build      # 型チェック + 本番ビルド（dist/）
```

コアは純粋関数 `generateCss(users, options)`（[`src/lib/generateCss.ts`](src/lib/generateCss.ts)）に集約し、
Streamkit 互換フォーマットの正しさを vitest で固定しています。

## デプロイ

公開先: **https://obs-tachie-generator.max-enterme.workers.dev/**

**Cloudflare Workers（Static Assets）の Git 連携**（build: `npm run build` / deploy: `npx wrangler deploy` / Node 22）。
